| Keyword | Ý nghĩa |
|---|---|
| `class` | Định nghĩa class |
| `struct` | Định nghĩa kiểu dữ liệu tổng hợp |
| `public` | Quyền truy cập công khai |
| `private` | Quyền truy cập riêng trong class và friend |
| `protected` | Quyền truy cập dành cho class, friend và lớp dẫn xuất theo quy tắc |
| `virtual` | Hỗ trợ runtime polymorphism |
| `override` | Xác nhận ghi đè virtual function |
| `final` | Ngăn kế thừa hoặc ghi đè |
| `static` | Thành viên gắn với class thay vì từng instance |
| `const` | Áp đặt ràng buộc không sửa đổi |
| `explicit` | Ngăn một số phép chuyển đổi ngầm định |
| `friend` | Cấp quyền truy cập đặc biệt |
| `this` | Con trỏ đến object hiện tại |
| `mutable` | Cho phép sửa member trong một số ngữ cảnh `const` |
| `using` | Khai báo alias hoặc đưa tên vào phạm vi |
| `= default` | Yêu cầu compiler cung cấp implementation mặc định |
| `= delete` | Cấm sử dụng function cụ thể |
